# QC suite implementation plan (v0.2.0)

**Spec:** `docs/superpowers/specs/2026-10-12-qc-suite-design.md` (approved 2026-10-12).
**Execution:** inline, TDD (failing test → implementation → green) per task. One PR into protected `main`.

## Global constraints
- Inputs are SEs from `annotate_probes()`. Outputs are `DataFrame`s and ggplots in the lab style.
- No new Imports; EpiDISH in Suggests.
- The control-locus coordinates live in `inst/extdata/qc_loci.csv`, using CoRSIV 2.0 1-based IDs.
- Errors are user-facing (`call. = FALSE`). Skipped checks return `status = "skipped"` with a reason; they never error.
